# Brand logo

Place the official AutomationEdge logo here as **`automationedge-logo.svg`** (preferred) or
**`automationedge-logo.png`**.

The `BrandLogo` component (`client/src/components/ui/BrandLogo.jsx`) tries the SVG first, then the PNG,
and falls back to a text wordmark ("Automation" + orange "Edge") if neither file exists.
Do not draw or approximate the logo — use the official file only.
